tiny-voca español

Un modelo de texto a voz en español de 4,5 millones de parámetros, con dos voces, entrenado desde cero. Esta página lo ejecuta en tu navegador: lo que escribes no sale de tu dispositivo.

A 4.5M-parameter Spanish text-to-speech model, trained from scratch. It runs here, in your browser.

Cómo funciona

  
    
    
  1. eSpeak NG 1.52.0, compilado a WebAssembly, convierte el texto en fonemas.
    2. 
    
  2. Un pequeño codificador predice la duración, el tono y la energía de cada fonema.
    3. 
    
  3. Un generador de onda de fuente y filtro produce el audio: pulsos armónicos con ruido por encima del segundo y del 33.º armónico.
    4. 
    
  4. ONNX Runtime Web ejecuta el modelo en tu procesador, frase a frase, y el audio empieza a sonar con la primera.
    5. 
  

  
La primera visita descarga unos 23 MB (el modelo desde Hugging Face y eSpeak NG); las siguientes arrancan sin red.
     Las palabras extranjeras y los nombres poco comunes a menudo se pronuncian mal. Los acentos rioplatense y caribeño
     cambian solo los fonemas: las voces se entrenaron en castellano.


  
Úsalo en tu equipo

  
git clone https://github.com/stdevMac/tiny-voca
cd tiny-voca
./run-es.sh        # instala, descarga el modelo y abre http://127.0.0.1:8000

  
Necesita Python 3.10+ y espeak-ng 1.52.0 (macOS: brew install espeak-ng).
     El modelo, el entrenamiento y los datos están documentados en el
     repositorio.
